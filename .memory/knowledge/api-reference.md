# mcp-manager — API Reference (contracts to code against)

> Exact shapes/endpoints. Design → `architecture.md`. Rationale → `decisions.md`.

## Proxy endpoints (same-protocol = verbatim passthrough)
- `GET /v1/models` → `{ object:'list', data:[{ id:<upstream model>, object:'model', created, owned_by:'mcp-manager' }] }` (single entry from `config.upstream.model`).
- `POST /v1/chat/completions` → OpenAI pass-through. Upstream model taken from the REQUEST BODY `model` field (not config); body (incl. `messages`, `tools`) forwarded verbatim, response returned verbatim. No auth required (`Authorization`/`x-api-key` read only as client identity, default `'anonymous'`). Configure real backend via env vars.
- `POST /v1/messages` → Anthropic pass-through. Cross-protocol pairs translated by `proxy/translate.ts` only when client protocol ≠ upstream protocol.
- Unmatched paths → 404. Optional `x-session-id` header (case-insensitive) feeds loop detection.
- To connect an OpenAI SDK client: `base_url=http://localhost:8787/v1`, `api_key=anything`, send your real upstream model in `model`.

## REST (`src/api/http.ts`, `createApiHandler({ruleStore, collector, specs?}) → (req,res)=>Promise<boolean>`)
Prefix `/api`; JSON Content-Type; non-`/api` returns `false`.
- `GET /api/stats` → `CollectorSummary` (see Key type contracts): beyond `totalCalls`/`totalResults`/`topTools`/`interventions`, now also exposes `totalDurationMs?`/`avgDurationMs?`/`totalInputTokens?`/`totalOutputTokens?`/`totalTokens?`, and each `topTools[]` entry carries optional `{avg,max,total}DurationMs?` for tool-call duration + token metrics (fields flow from `collector.summary()`, no handler change).
- `GET /api/events` → `{ events: TelemetryEvent[] }` (most-recent raw telemetry events, ascending, ≤ recent cap) — feeds the dashboard's polling fallback.
- `GET /api/rules` → `RuleSpec[]` (prefers originally-submitted spec stored server-side, else best-effort `describeRule`).
- `POST /api/rules` → body `RuleSpec` → `201 { id, ...spec }` (assigns id if missing); invalid → `400 { error }`.
- `PATCH /api/rules/{id}` → partial update (e.g. `{enabled}`, or new matcher/action) → `200` serialized rule; unknown → `404 { error:'not_found' }`.
- `DELETE /api/rules/{id}` → `204`; unknown → `404`.

## WebSocket (`src/api/ws.ts`, `createWsServer(server, {bus?}) → { close(); get size }`)
Attaches via HTTP `Upgrade` (raw RFC6455 over Node sockets, no `ws`). `Sec-WebSocket-Accept = base64(sha1(key + '258EAFA5-E914-47DA-95CA-C5AB0DC85B11'))`. Connect: `ws(s)://<host>/ws`. Inbound broadcast frames are verbatim `TelemetryEvent` JSON; each client text frame is echoed as `{ echo: <parsedJson|rawString> }`.

## Dashboard statics (same-origin)
`GET /` → `index.html`; `GET /app.js`; `GET /styles.css`. SPA polls `/api/stats` (~3s) and subscribes to WS for live events.

## Key type contracts
- `PolicyRule { id; enabled; priority?; description?; matcher:PolicyMatcher; action:PolicyAction }` (**NO `name` field**). `PolicyMatcher.matches(ctx): Match|null`; `Match { matched; reason; details? }`. `PolicyAction.apply(ctx): ActionEffect|null`.
- `createRuleEngine(rules: PolicyRule[] | (()=>PolicyRule[])): RuleEngine { evaluate(ctx): RuleEvaluationResult }`; `RuleEvaluationResult { effects; matches:[{ruleId,match}]; applied:[{ruleId,effect}] }`.
- `ActionEffect = {type:'block'; toolCallIds?; message} | {type:'hideTool'; toolNames:string[]} | {type:'rewriteArgs'; toolCallId; newArguments} | {type:'injectMessage'; role:'user'|'system'; content:string}`.
- Factory option shapes (verbatim): loop `{ window?; requireConsecutive?; paramIdentity?:'exact'|'normalized'; resultIdentity? }`; toolName `{ toolName?; toolNames? }`; argPattern `{ toolName?; toolNames?; pattern: string|RegExp }`; block `{ reason?; message?; template? }`; hideTool `{ toolNames:string[] }`; rewriteArgs `{ toolName?; toolCallId?; arguments:Record<string,unknown>; mode? }`; injectMessage `{ role?:'user'|'system'; content:string }`. Matcher factories return `PolicyMatcher`; action factories return a port `Action`.
- `RuleSpec` (`src/api/ruleSpec.ts`) = `{ id?; enabled; priority?; description?; matcher:MatcherSpec; action:ActionSpec }`; `buildRuleFromSpec(spec): PolicyRule`; `describeRule(rule): RuleSpec`; `validateSpec(value): string|null`.
- Telemetry events (`at:number`): `ToolCallEvent { type:'tool.call'; sessionKey; clientId?; toolName; args?; id?:string; tokens?:{input?:number;output?:number;total?:number}; at }` (`id`: STABLE UNIQUE per emitted call — upstream tool-call id verbatim, else deterministic `${sessionKey}#${at}#${index}` with `~N` disambiguation on same-turn collision; the dashboard's dedup key; type stays optional but both emitters always populate it; `tokens` = upstream turn usage as `{input?,output?,total?}`, present ONLY when the provider reports usage — absent on a no-usage turn); `ToolResultEvent { type:'tool.result'; sessionKey; clientId?; toolName; ok?; toolCallId?; durationMs?:number; chars?:number; at }` (now a REAL per-result event, paired by id across requests); `InterventionEvent { type:'policy.intervention'; sessionKey; ruleId; action:InterventionAction; detail?; at }`; `InterventionAction = ActionEffect['type']`.
- `Collector` (`createCollector({bus?, maxInterventions?=500, maxRecent?=200, maxTokenTurns?=10000, excludedTools?:readonly string[]} = {…excludedTools default ['task']})`): `getTopTools(n?)`, `getInterventions(limit?)`, `getRecentEvents(limit?): TelemetryEvent[]` (ascending, defensive copy — raw retention NOT filtered), `summary(): CollectorSummary`; readonly `perTool`/`perSession` maps; `reset()` (clears recent + metric aggregates), `dispose()`. Aggregates per-tool `{avg,max,total}DurationMs` and global token/duration totals (tokens deduped per `(sessionKey, at)` turn). Events whose `toolName` matches `excludedTools` are dropped from ALL aggregates (totals + averages + top-tools) but kept in raw retention — see `src/telemetry/aggregate-exclusions.ts`.
- `CollectorSummary = { totalCalls; totalResults; topTools:TopTool[]; interventions:InterventionEvent[]; totalDurationMs?; avgDurationMs?; totalInputTokens?; totalOutputTokens?; totalTokens? }`; `TopTool = { toolName; count; avgDurationMs?; maxDurationMs?; totalDurationMs? }`. The new metrics fields are OPTIONAL (omitted until data exists), so earlier shapes stay valid.
- `ToolMetricsTracker` (`src/telemetry/toolMetrics.ts`, `createToolMetricsTracker({maxPending?=1000, ttlMs?=300000, now?=Date.now})`): bounded cross-request pairing — `recordIssued(sessionKey, {id,at,name?}[])`, `resolveResults(sessionKey, {toolCallId?,at,chars?}[]): {toolCallId,durationMs,chars?,toolName?}[]`, `pendingCount()`, `reset()`. In-memory only, no timers (TTL+cap enforced lazily via injectable clock). Primary match is same-session `${sessionKey}\u0000${id}`; on miss it falls back to matching BY `toolCallId` across sessions (most-recent compatible entry) so a diverging/empty `x-session-id` can't strand a call.
- `aggregate-exclusions.ts` (`src/telemetry/aggregate-exclusions.ts`): exports `DEFAULT_AGGREGATE_EXCLUDED_TOOLS = ['task']` and `isAggregateExcluded(toolName, excludedTools?)` (case-insensitive) — the set of tool names omitted from all collector aggregates (default filters out the nested sub-agent wrapper `task`). See `tool-metrics.md` / `decisions.md`.
- `RuleStore` (`createRuleStore({initial?})`): `list()`(copy), `get(id)`, `add(rule)`(auto randomUUID id if missing), `update(id,patch)`, `remove(id)`, `reset()`, `size()`. Defensive copies.
- `createProxyHandler(options): (req,res)=>Promise<boolean>` with non-enumerable `.telemetry = { bus; collector; tracker; storage? }` (`tracker` = shared `ToolMetricsTracker`). `ProxyOptions { upstream:UpstreamClient; pipeline?; policy?{ rules; feedback?; sessionIdHeader?='x-session-id' }; telemetry? }`.
- `createServer(port?, options?:ProxyOptions, mount?:MountOptions): McmServer`; `MountOptions { ruleStore?; initialRules?:PolicyRule[]; dashboardDir?; ws? }`; `McmServer = http.Server & { readonly mcm?: McmServerHandle }`; `McmServerHandle { bus; collector; tracker; storage?; ruleStore; apiHandler; ws }` (non-enumerable). Dashboard dir resolved by walking up from `__dirname` (≤4 levels) to the first containing `dashboard/index.html` (or `mount.dashboardDir`).

## Config env vars
`PORT` (8787 → `port`), `UPSTREAM_BASE_URL` (`http://127.0.0.1:9005/v1` → `upstream.baseUrl`), `UPSTREAM_MODEL` (`gpt-4o-mini` → `upstream.model`), `UPSTREAM_API_KEY` (unset → `upstream.apiKey`), `UPSTREAM_PROTOCOL` (`openai` → `upstream.protocol`; only `anthropic` selects Anthropic).
